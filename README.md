# 新北市土城區 1:1 GIS 數位孿生與長風新城採光模擬 (Godot 4 + Blender + Web)

本專案為新北市土城區（涵蓋**長風新城**、**城林大橋**、**大安圳**、**捷運土城站**與周邊 369 棟街廓建築）的 1:1 真實比例 GIS 數位孿生與動態日照模擬系統。

專案同時提供 **Godot 4 遊戲引擎即時運行環境**、**Blender 5.2+ 原生 3D 建模源檔**，以及基於 **Three.js 的 Web 3D 互動漫遊檢視器**。

---

## 🌟 核心成果與幾何修訂

1. **長風新城雙中庭花園完全露出版**：
   - 經幾何座標與頂點包圍盒精密定位，徹底刪除了原先壓在中庭綠地正中央與入口的 3 棟巨型遮擋建物（`Mesh_1052`、`Mesh_1051`、`Mesh_1053`）以及舊混擬土地基板。
   - 保留的兩側住宅翼棟對稱外擴，釋出超過 40~50 米淨寬的開闊綠化陽光中軸通廊。
2. **雙中庭景觀深度重構**：
   - **北側大中庭**（原 1052 遮擋處）：順應街廓軸向（$-32.8^\circ$），配置 $96\,\text{m} \times 64\,\text{m}$ 翠綠 PBR 大草坪、中央石磚景觀步道、四柱木造休閒涼亭（Gazebo）與對稱林蔭綠樹。
   - **南側露天花園**：配置 $42\,\text{m} \times 56\,\text{m}$ 景觀草坪、石磚廣場、景觀涼亭與綠樹，南北兩大中庭視線 100% 暢通穿透。
3. **土城市街 1:1 真實地理還原**：
   - 東西跨度 $2.2\,\text{km}$、南北跨度 $1.7\,\text{km}$（涵蓋面積達 $3.7\,\text{km}^2$）。
   - 還原大漢溪沖積平原真實平坦地勢，徹底移除早期突兀假山；收錄 722 條實測道路與 1,033 米城林大橋。

## 🎮 如何使用與體驗

### 1. Godot 4.7+ 桌面端即時模擬（推薦）

專案根目錄即為標準 Godot 4 專案：

- **快速啟動**：直接雙擊執行目錄下的 [`start.bat`](start.bat)。
- **編輯器開啟**：開啟 Godot 4 編輯器（建議 4.7+），點擊「匯入」並選擇本專案資料夾，按 **`F5`** 即可進入全螢幕動態漫遊。

**Godot 操作指南**：
| 按鍵 / 動作 | 功能說明 |
| :--- | :--- |
| **滑鼠右鍵（按住）+ 滑鼠移動** | 第一人稱視角 360 度旋轉自由環視 |
| **W / A / S / D** | 前進 / 左平移 / 後退 / 右平移（按住 **Shift** 可加速 3 倍） |
| **E / Q** | 視角垂直上升 / 下降 |
| **鍵盤 1** | 切換至 **☀️ 正午日光**（垂直立體陰影，日照最強） |
| **鍵盤 2** | 切換至 **🌇 夕陽西下**（大漢溪西方低角度金色夕陽與長陰影） |
| **鍵盤 3** | 切換至 **🌅 清晨破曉**（柔和粉紫晨曦） |
| **F** | 開啟 / 關閉 **體積迷霧（Volumetric Fog）與大氣光線散射** |
| **R** | 開啟 / 暫停 **太陽動態公轉**（自動模擬晝夜日照流動） |

---

### 2. Blender 5.2+ 3D 原始模型

模型源檔存放於 [`blender/`](blender/) 目錄下：
- [`blender/長風新城_中庭花園露出版.blend`](blender/長風新城_中庭花園露出版.blend)：包含已刪除遮擋棟、建立中庭草坪、廣場、涼亭與林蔭樹的原生場景。
- 開啟方式：於 Blender 中點擊 `File ➔ Open...`（快捷鍵 `Ctrl + O`）選擇該檔案，切換至 `Material Preview` 或 `Rendered` 視圖即可編輯。

---

### 3. Web 3D 瀏覽器即時漫遊 (Three.js)

免安裝任何軟體，透過瀏覽器即可 3D 漫遊：

- **本地啟動**：
  ```bash
  python server.py
  ```
  在瀏覽器開啟 **`http://localhost:8088`** 即可體驗。
- **GitHub Pages 線上預覽**：
  在 GitHub 儲存庫設定中將 Pages 來源設為 `main` 分支根目錄（`/`），即可透過 `https://karst10607.github.io/reien-godot/` 線上即時展示。

**Web 操作指南**：
- **滑鼠左鍵拖曳**：環繞目標地標 360 度旋轉
- **滑鼠滾輪**：縮放觀察距離
- **滑鼠右鍵拖曳**：自由平移視角中心
- **鍵盤 WASD / QE**：第一人稱飛行漫遊
- **頂部地標膠囊按鈕**：一鍵瞬間移動至「長風北中庭」、「長風南中庭」、「城林大橋」、「捷運土城站」或「1500m 全景鳥瞰」
- **採光按鈕**：正午、夕陽、晨曦、夜色、太陽動態公轉

## 📐 地理與日照物理校準

- **地理座標中心**：GPS $24.9765^\circ\,\text{N},\; 121.4370^\circ\,\text{E}$（新北市土城區中央路二段與長風新城交界）。
- **座標軸對齊**：
  - $+X$：正東方（往天上山脈 / 捷運土城站方向）
  - $-X$：正西方（往大漢溪 / 城林大橋 / 樹林方向）
  - $+Z$（glTF/Web）：正南方（往頂埔 / 三峽方向）
  - $-Z$（glTF/Web）：正北方（往板橋 / 湳仔溝方向）
- **真實日照軌跡**：太陽自東方低空升起，正午於南方高空以近垂直角度（夏秋季仰角 $68^\circ \sim 80^\circ$）照射，傍晚於西方大漢溪地平線投射金色長條陰影。
